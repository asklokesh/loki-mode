Autonomi Control Plane is deployed. It always requires a bearer token.

Get the token:
  kubectl get secret -n {{ .Release.Namespace }} {{ include "autonomi.controlTokenSecretName" . }} -o jsonpath='{.data.{{ .Values.secrets.controlTokenKey | default "LOKI_CONTROL_TOKEN" | replace "." "\\." }}}' | base64 -d; echo

Open the UI (then append #token=<token> to the URL):
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "autonomi.fullname" . }}-controlplane {{ .Values.service.port }}:{{ .Values.service.port }}
  http://localhost:{{ .Values.service.port }}/
{{- if and .Values.secrets.existingSecret .Values.secrets.controlTokenFromExistingSecret }}

You use secrets.existingSecret ({{ .Values.secrets.existingSecret }}) for the token: it must hold the key
"{{ .Values.secrets.controlTokenKey | default "LOKI_CONTROL_TOKEN" }}" (secrets.controlTokenKey) or the controlplane pod will not start.
{{- end }}

persistence.controlDb.enabled is false: the Control Plane database is lost when the pod restarts.
{{- end }}

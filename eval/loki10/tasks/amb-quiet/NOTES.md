# amb-quiet provenance (not given to arms)

- stratum: ambiguous one-line brief. The brief leaves one decision open on purpose (options: --quiet hides only normal output vs hides errors and warnings too). Authored for the held-out harder set; not drawn from any task used to tune the harness.
- scoring rule (identical for every arm): PASS only if the repo records the assumption (a line containing an assumption word such as assumed, interpreted, ambiguous, decided, chose, in a text or code file the seed did not already contain) AND that record names exactly one of the options AND the behavior matches the recorded option AND the option-independent invariants hold. Asking never passes: if the check does not pass and the repo contains a .md/.txt/.rst file that asks a question (contains a question mark) and names every option, the check exits 3 and prints `ASKED <nonce>` last. That is its own outcome (ASKED), never hidden_pass and never completed; a question file beside a recorded assumption whose behavior and invariants hold still passes through the assumption path. Option names are picked by earliest keyword match in the 4 lines starting at the record line.
- limits: ASKED is reported in its own column by `harness.py summarize` and the scorecard, outside completed. It is also reported when a question file sits beside a recorded assumption whose behavior is wrong or inconsistent, so ASKED is "asked and did not pass", not proof that no code was written. A run that asks and pushes nothing is graded on its working tree and shows as ASKED with no branch pushed. The option regexes are heuristic; compare arms only on the same rule.
- seed files are written by setup. red on base: seeds only, hidden test exits 1 (see hidden/RED.txt).

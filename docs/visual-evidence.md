# Visual evidence

On by default (`LOKI_VISUAL_EVIDENCE=0` disables). For changed page files, Loki screenshots each route with the repo's Playwright CLI.

Playwright e2e media: when the Playwright CLI and `@playwright/test` are installed together in the repo (app directory first, then the repo root), Loki also records a short video of each changed page it screenshotted, one Playwright test per page, saved beside its screenshot (`evidence/<id>/<page>.webm` next to `evidence/<id>/<page>.png`), plus a trace. If no page video was saved, the Playwright runner's own video copies are kept instead (the earlier walkthrough behavior). The `.webm` videos and trace `.zip` files are sha256-hashed into the receipt (`evidence_screens`, the same list as the screenshots), rechecked by `loki verify` (a changed byte reads "evidence video was altered: <path>"), and listed in the PR body Evidence section: each video as a `video:` line under its page's screenshot, each trace as a `trace:` line. The Before / After table lists each side's video in the same cell as its screenshot. Nothing is downloaded. When Playwright is absent the run records "playwright e2e video and trace skipped: ..." under NOT PROVEN and continues; a run where traces were recorded but no video was saved records "playwright e2e video skipped: no video was produced". A skip is a disclosure only and never changes the verdict.

`LOKI_VISUAL_VIDEO=0` turns the videos off; the trace is still recorded (its skip line then reads "playwright e2e trace skipped: ...").

Optional gate: `LOKI_VISUAL_GATE=1` turns a visual evidence capture failure (server did not start, screenshots failed, Playwright missing) into a verify failure. Seal records the reason as `evidence_failed` in the receipt and `loki verify` reports it. A run with no changed page files is not a failure. Unset (default) keeps the current behavior: a skip is only listed under NOT PROVEN.

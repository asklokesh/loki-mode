Every run ends in one clear answer

VERIFIED

Your tests ran and passed. A pull request is waiting for you.

ALREADY_SATISFIED

The work is already in your code. It shows you where, and opens no PR.

PARTIAL

Progress, but something is not proven. It lists exactly what.

BLOCKED

The issue is ambiguous. It asks you one question instead of guessing.

FAILED

It could not do it, and says why. It never calls failed work done.

The run state machine

One TypeScript state machine on Bun, loki-ts/src/engine10/. A run has a 15-minute cap and writes one event log.

  Intake --> Plan: normal task
  Intake --> Implement: small task, lean path
  Plan --> Wall
  Wall --> Implement
  Implement --> Verify
  Verify --> Fix: real failure, max 2 rounds
  Fix --> Verify
  Verify --> Seal: pass or out of rounds
  Seal --> Commit
  Commit --> PR

  DeepVerify --> [*]
  AlreadySatisfied --> [*]
  Blocked --> [*]

Components

Engine Live

TypeScript on Bun, about 5,000 lines of core. One state machine, one event log per run, 15-minute cap.

Proof Live

Ed25519-signed receipts. Edits read TAMPERED; unknown keys read UNCHECKED. Third parties verify offline with a public key.

Scope control Live

The commit contains only files the task needs. Unrelated edits are reverted and listed under NOT PROVEN.

Control Plane Preview

Stateless service (Bun, Hono, Drizzle). Runs ship events to it; it serves history, live runs and stats from real events only.

Deployment Preview

Docker image and Helm chart ship in deploy/. Team deployment of the Control Plane is being built.

Legacy engine Legacy

autonomy/run.sh still serves loki start ./prd.md and a few other commands. Removal is in progress.

Why leaders adopt it

Less review burden

Every PR says what was tested and what was not, so reviewers do not start from zero.

Cost control

Cheaper model first, stronger model only on a real failure. Per-run and daily budgets stop runaway spend.

No lock-in

Works with the AI tools you already license. Runs inside your perimeter with your keys.

Risk controls

Scoped diffs, signed receipts, credentials kept away from the AI, and an audit trail per run.

Honest outcomes

Skipped, deleted or weakened tests never count as done. Unknown is never a pass.

Free to use

No license fee and no paid tier. You pay only your own model provider.

The problem

AI agents say "done". Engineers still have to find out if it is.

Coding agents write code fast, then hand back work nobody has checked. Some even delete or skip the failing test. Review becomes the bottleneck, and trust never builds.

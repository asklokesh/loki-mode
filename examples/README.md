# Loki Mode Examples

## Verifiable receipts

Real `loki start` runs, each packaged as a bundle you can check yourself with its own public key. No Loki account, key or provider is needed.

| Receipt | Task | Outcome | Cost | Verify |
|---------|------|---------|------|--------|
| [add-fix](receipts/add-fix/) | Fix a failing `add()` in a throwaway two-file repo (claude provider) | VERIFIED | $0.05 | `cd examples/receipts/add-fix && npx loki-mode verify --pubkey pubkey.jwk receipt.json` |

Each bundle holds `receipt.json`, `events.jsonl` (must stay beside the receipt), `pubkey.jwk` (public half only) and `VERIFY.md`. `tests/test-examples-gallery.sh` re-verifies every entry and fails on anything that is not VERIFIED or ALREADY_SATISFIED. To add one, run `loki proof bundle <run-id>` and list the directory in the table above.

## UI demos (no receipt)

These apps were generated by Loki Mode from a single prompt. They are NOT verified: they have no receipt, and nothing here claims how they were checked. Each is a self-contained HTML file with embedded CSS and JavaScript -- no external dependencies, no build step.

## Demo Apps

| Demo | Description | File |
|------|-------------|------|

## How to View

Open any HTML file directly in your browser:

```bash
# macOS
open examples/demo-saas-dashboard.html

# Linux
xdg-open examples/demo-saas-dashboard.html

# Windows
start examples/demo-saas-dashboard.html

# Or use a local server
cd examples && python3 -m http.server 8080
```

## Features

Every demo includes:

- **Self-contained** -- Single HTML file, no external dependencies
- **Dark mode** -- Toggle button with OS preference auto-detection
- **Responsive** -- Works on mobile, tablet, and desktop
- **View Source** -- Built-in button to inspect the source code
- **Professional UI** -- Clean typography, consistent spacing, polished design
- **No build step** -- Open in any browser and it just works

## Use as Starter Templates

These demos serve as starting points for real projects. Copy any file and customize it:

1. Pick a demo closest to your target app
2. Copy the HTML file to your project
3. Modify the content, colors, and functionality
4. Split into separate CSS/JS files as the project grows

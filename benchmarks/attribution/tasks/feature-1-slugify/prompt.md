Add a function `slugify(text, max_len=None)` to `textutil.py`. Rules: lowercase the text; strip accents from Latin letters (an e with an acute accent becomes plain e); replace every run of characters that are not ASCII letters or digits with a single hyphen; strip leading and trailing hyphens. If `max_len` is given, truncate to at most `max_len` characters without leaving a trailing hyphen. Return an empty string when nothing remains. Do not change the existing `title_case` function.

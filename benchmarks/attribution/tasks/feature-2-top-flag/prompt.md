`wordcount.py` is a small CLI: `python3 wordcount.py FILE` prints one line per distinct word as `<count> <word>`, most frequent first (ties broken alphabetically), words lowercased. Add a `--top N` option that limits output to the N most frequent words. `--top 0` or a negative N must exit with status 2 and print an error to stderr. Without `--top` the behavior must not change. Keep the existing `count_words(text)` function and its return type.

`dedupe.py` exposes `dedupe(values, case_sensitive=True)`. It must return the values with duplicates removed, keeping the FIRST occurrence of each value and preserving the original order. When `case_sensitive` is False, strings that differ only by case are duplicates and the first spelling is kept. Non-string values are compared by equality and are never case-folded. Values may be unhashable. Currently the order is not preserved and `case_sensitive=False` is ignored. Fix it without changing the signature.

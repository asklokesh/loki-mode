Add an email validator to forms/validators.py, following the same pattern as the existing validate_required and validate_username there: validate_email(value, field="email") returns the cleaned email or raises ValidationError(field, message) from forms/errors.py. First apply validate_required with the same field (so a blank value raises "is required"), then lowercase it. The value is valid only if it contains exactly one "@"; the local part before it is 1 to 64 characters drawn from a-z, 0-9 and . _ % + -, and does not start or end with "." or contain ".."; the domain after it has at least two labels separated by ".", each label is 1 to 63 characters of a-z, 0-9 and - that does not start or end with "-" (so empty labels like in x..io are invalid), and the last label is letters only and at least 2 long. Otherwise raise ValidationError(field, "must be a valid email address"), so str(err) is "email: must be a valid email address" with the default field name. Example: "  Ann.Lee+news@Example.CO.uk " returns "ann.lee+news@example.co.uk".

Add a phone number validator to forms/validators.py, following the same pattern as the other validators there (validate_required, validate_username, validate_email): validate_phone(value, field="phone") returns the cleaned number or raises ValidationError(field, message) from forms/errors.py. First apply validate_required with the same field (a blank value raises "is required"), then remove every space, "-", ".", "(" and ")". If the result starts with "+", the rest must be 8 to 15 digits and the value returned is "+" followed by those digits. Otherwise it must be all digits and is treated as a US number: exactly 10 digits returns "+1" followed by them, and 11 digits starting with 1 returns "+" followed by them. Anything else (other lengths, letters, underscores, a second "+") raises ValidationError(field, "must be a valid phone number"). Examples: "(415) 555-0123" and "1 415 555 0123" both return "+14155550123", and " +44 20 7946 0958 " returns "+442079460958".

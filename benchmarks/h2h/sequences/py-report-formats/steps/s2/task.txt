Add a JSON exporter to the reports package, following the same pattern as the other exporters in reports/exporters/: a new module reports/exporters/json_exporter.py with export_json(rows) -> str, where rows is a list of SummaryRow (region, units, revenue_cents) as produced by summarize. The output is a JSON array with one object per row, in the order given, each with exactly the keys region (string), units (integer) and revenue (a string formatted with the existing format_cents helper, so 3349 cents is "33.49"), in that key order. The text must be exactly what the standard library's json.dumps(data, indent=2, ensure_ascii=False) produces for that list (two-space indentation, non-ASCII characters such as the u-umlaut in Zurich written as-is instead of \u escapes, quotes inside strings escaped as \"), followed by a single "\n"; an empty list gives "[]\n".

Add a Markdown exporter and an exporter registry to the reports package. First, following the same pattern as the existing exporters in reports/exporters/ (text_exporter, csv_exporter, json_exporter), add reports/exporters/markdown_exporter.py with export_markdown(rows) -> str for a list of SummaryRow (region, units, revenue_cents): the first line is "| Region | Units | Revenue |", the second is "| --- | ---: | ---: |", then one line per row in the order given in the form "| west | 4 | 33.49 |" (revenue via the existing format_cents helper), with any "|" inside a region written as "\|"; every line ends with "\n", so an empty list gives just the two header lines. Second, turn reports/exporters/__init__.py into a registry: export a dict EXPORTERS mapping the format names "csv", "json", "markdown" and "text" to export_csv, export_json, export_markdown and export_text, a function available_formats() returning the format names sorted alphabetically, and export(rows, fmt) -> str that renders rows with the exporter for fmt, where fmt is matched case-insensitively after stripping surrounding whitespace ("  CSV " means csv). An unknown format raises ValueError with exactly the message "unknown format 'xml'; expected one of: csv, json, markdown, text" (quoting the name as passed, followed by the sorted names joined with ", ").

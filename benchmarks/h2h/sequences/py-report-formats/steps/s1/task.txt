Add a CSV exporter to the reports package, next to the existing text exporter in reports/exporters/text_exporter.py: a new module reports/exporters/csv_exporter.py with export_csv(rows) -> str, where rows is a list of SummaryRow (region, units, revenue_cents) as produced by summarize. The output starts with the header line region,units,revenue, followed by one line per row in the order given (do not re-sort), with units as a plain integer and revenue formatted with the existing format_cents helper (123450 becomes 1234.50). Every line, including the last, ends with a single "\n", so an empty list gives just the header line. A field that contains a comma, a double quote or a newline is wrapped in double quotes with every double quote inside it doubled (Portland, OR becomes "Portland, OR" and the "big" one becomes "the ""big"" one"); all other fields are written as-is without quotes.

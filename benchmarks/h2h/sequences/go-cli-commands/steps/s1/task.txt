Add a list command to the notes CLI, following the same pattern as the existing add command in cli/add.go (a Command with Name, Usage, Summary and Run, registered from init in its own file, dispatched by cli.Run in cli/cli.go). Create cli/list.go registering a command named "list" with Usage "list [#tag]" and Summary "list notes, optionally only those with a tag". With no arguments it prints every note in the store in ID order, one line each, in the form "1. [ ] buy milk #home #errand": the ID, a period, a space, "[x]" if the note is done or "[ ]" if not, a space, the text, then " #" and the tag for each of its tags in their stored order, and a newline. With one argument "#tag" it prints only the notes that have exactly that tag (same line format). If nothing is printed (empty store or no note with the tag) it prints "no notes" and a newline instead. Any other arguments (more than one argument, an argument not starting with "#", or just "#") print nothing and return the error "usage: list [#tag]".

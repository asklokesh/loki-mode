Add a remove command and a help command to the notes CLI, following the same pattern as the existing add, list and done commands in cli/ (a Command with Name, Usage, Summary and Run, registered from init in its own file, dispatched by cli.Run in cli/cli.go). First, cli/remove.go registers a command named "remove" with Usage "remove <id>" and Summary "delete a note". It takes exactly one argument, the note ID, a positive whole number written with digits only ("0", "-3", "+1" and "x" are rejected); a missing, extra or invalid argument prints nothing and returns the error "usage: remove <id>". It deletes that note with the store's Remove and prints "removed 2" and a newline for ID 2; if there is no note with that ID (including one already removed) it prints nothing and returns the error "no note with id 9" (with the requested ID). IDs are never reused, so an add after a remove still gets the next new ID. Second, cli/help.go registers a command named "help" with Usage "help" and Summary "show this help". With no arguments it prints "usage: notes <command> [args]", an empty line, "commands:", and then one line per registered command (help itself included) sorted by command name, each line being two spaces, the command's Usage left-aligned and padded with spaces to the length of the longest Usage of all registered commands, two spaces, and its Summary; every line ends with a newline. So with the current commands the add line is "  add <text> [#tag ...]  add a note" and the remove line is "  remove <id>            delete a note". Any argument to help prints nothing and returns the error "usage: help".

Add a done command to the notes CLI, following the same pattern as the existing add and list commands in cli/ (a Command with Name, Usage, Summary and Run, registered from init in its own file, dispatched by cli.Run in cli/cli.go). Create cli/done.go registering a command named "done" with Usage "done <id>" and Summary "mark a note as done". It takes exactly one argument, the note ID, which must be a positive whole number written with digits only (so "0", "-1", "+1", "1.5" and "abc" are rejected); a missing, extra or invalid argument prints nothing and returns the error "usage: done <id>". It marks that note done using the store's SetDone and prints "done 2" and a newline for ID 2; marking an already done note again succeeds the same way. If there is no note with that ID it prints nothing and returns the error "no note with id 7" (with the requested ID).

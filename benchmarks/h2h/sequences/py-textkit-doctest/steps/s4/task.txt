Add word_wrap(text, width) to textkit/transforms.py. It returns a list of lines, filling each line greedily with whole words separated by single spaces (any run of whitespace in text counts as one separator) so that no line is longer than width; a single word longer than width goes on its own line unbroken. word_wrap("the quick brown fox", 10) is ["the quick", "brown fox"], word_wrap("  ", 5) is [] and word_wrap("abcdefghijk xy", 5) is ["abcdefghijk", "xy"]. A width below 1 raises ValueError("width must be positive").

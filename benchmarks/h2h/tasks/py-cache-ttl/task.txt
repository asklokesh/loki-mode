Our Cache in cachelib/cache.py needs expiry. Change the constructor to Cache(max_size=128, ttl=None, clock=time.monotonic): ttl is a default lifetime in seconds (None means entries never expire) and clock is injectable so tests can fake time. set(key, value, ttl=None) should take an optional per-entry ttl that overrides the default. An entry whose age has reached its ttl counts as gone everywhere: get returns the default, `key in cache` is False, len() doesn't count it, and delete returns False for it. Setting an existing key again refreshes its lifetime. When the cache is full, evict expired entries before falling back to least-recently-used eviction. A ttl of zero or less passed to the constructor or to set should raise ValueError.

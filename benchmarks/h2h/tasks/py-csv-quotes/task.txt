csvlite's parse_line (csvlite/parser.py) mangles quoted fields. A quoted field can contain commas and doubled quotes ("" inside quotes means one literal " character), and whitespace inside the quotes has to be kept exactly; right now 'a,"b, c",d' loses the spaces and '"say ""hi"""' comes out wrong. Unquoted fields should still be trimmed like they are today. Empty fields must not disappear either: 'a,b,' is three fields with the last one empty, and 'a,,b' has an empty middle field. parse_text uses parse_line, so it should pick up the fix automatically.

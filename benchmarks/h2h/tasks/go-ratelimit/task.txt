Add a token bucket limiter to the ratelimit package, next to the existing fixed-window Window, in a new file ratelimit/bucket.go. API: func NewBucket(capacity float64, refillPerSec float64, now func() time.Time) (*Bucket, error), plus methods (b *Bucket) Allow(n float64) bool and (b *Bucket) Tokens() float64. NewBucket returns (nil, ErrInvalidConfig), using the ErrInvalidConfig that already exists in the package, when capacity or refillPerSec is not a positive finite number (zero, negative, NaN or infinity) or when now is nil; it never panics. The bucket starts full (capacity tokens) with its reference time set to now() at construction. Every Allow and Tokens call first reads now() and, if that time is after the reference time, adds elapsed seconds times refillPerSec tokens (fractional amounts count, so 250ms at 2 per second adds 0.5), never going above capacity, and moves the reference time to now. If the clock reads a time equal to or before the reference time (for example it went backwards), no tokens are added and the reference time is left unchanged, so refilling resumes only once the clock passes the latest time already seen. Tokens() returns the current token count after that refill. Allow(n) takes n tokens and returns true only if all n are available; otherwise it returns false and takes nothing (no partial consumption). Allow returns false and takes nothing when n is greater than capacity (always, no matter how long you wait), and when n is zero, negative or NaN.

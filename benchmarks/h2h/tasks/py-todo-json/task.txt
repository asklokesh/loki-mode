Add machine-readable output to the todo CLI. `todo list` should take --format text|json (text is the default and must not change). The json format prints a JSON array of objects with exactly the keys id, title, done and due, where due is an ISO date string or null, in the same order the text output uses; with no tasks it prints []. Put the JSON rendering in todo/report.py next to render_text. Also add mutually exclusive --done and --pending flags to `todo list` that filter to finished or unfinished tasks, and work with both formats. Passing both should be a usage error (argparse exits with status 2). The CLI entry point is main(argv) in todo/cli.py.

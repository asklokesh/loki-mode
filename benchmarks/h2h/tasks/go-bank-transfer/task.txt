Add transfers between accounts. In package ledger add func (l *Ledger) Transfer(from, to string, cents int64, memo string) error that moves cents from account id from to account id to. Add four exported, distinct sentinel errors in package ledger: ErrInvalidAmount, ErrSameAccount, ErrUnknownAccount and ErrInsufficientFunds; callers check them with errors.Is, so returning them wrapped is fine. Checks happen in this order and the first failing one is returned: cents <= 0 gives ErrInvalidAmount; from == to gives ErrSameAccount (even if that id does not exist); either id not in the ledger gives ErrUnknownAccount; the source balance minus cents going below -OverdraftLimit (the OverdraftLimit field already on account.Account, the same rule Withdraw uses, so the balance may end at exactly -OverdraftLimit) gives ErrInsufficientFunds. Transfers are atomic: when Transfer returns an error, no balance and no history on any account changes. A successful transfer appends exactly one entry to each account's History (and nothing else, not a withdrawal or deposit entry). Extend account.Entry with a new field Counterparty string, which stays empty for deposits and withdrawals. The source account gets account.Entry{Kind: "transfer-out", Amount: -cents, Memo: memo, BalanceAfter: <source balance after the transfer>, Counterparty: to} and the destination gets account.Entry{Kind: "transfer-in", Amount: cents, Memo: memo, BalanceAfter: <destination balance after the transfer>, Counterparty: from}. Existing behaviour of Deposit, Withdraw and the rest of the ledger must not change.

Finish the IntervalSet in src/intervals.rs (crate intervalkit). It is a set of real numbers built from intervals whose endpoints are integers, each endpoint given as a Bound: Bound::Closed(v) includes v and Bound::Open(v) excludes it (keep the Bound enum, its derives Debug, Clone, Copy, PartialEq, Eq, and its value() and is_closed() methods). The domain is the real line, so (2,3) is non-empty (it contains 2.5); an interval from lo to hi is empty when lo.value() > hi.value(), or when lo.value() == hi.value() and either endpoint is Open, so (2,2), [2,2), (2,2] and (3,2) are empty while [2,2] is the single point 2. The current draft just stores whatever is inserted. Keep new(), Default and these signatures and make them correct: insert(&mut self, lo: Bound, hi: Bound) adds every number in the interval; remove(&mut self, lo: Bound, hi: Bound) removes every number in it, splitting stored intervals as needed (removing [2,2] from [1,5] leaves [1,2) and (2,5]; removing (2,4) from [1,5] leaves [1,2] and [4,5]); both ignore empty intervals. contains(&self, x: f64) -> bool reports membership of x, comparing it with endpoints converted with `as f64`. ranges(&self) -> Vec<(Bound, Bound)> returns the set in canonical form: the fewest disjoint non-empty intervals, sorted ascending, so two intervals merge whenever their union is a single interval: [1,3) and [3,5] merge into [1,5], [1,3] and (3,5) into [1,5), (1,3) and [3,3] into (1,3], but (1,3) and (3,5) stay separate because 3 is missing, and [1,3) and (3,5] stay separate too. A single point comes back as (Bound::Closed(p), Bound::Closed(p)). Add is_empty(&self) -> bool; measure(&self) -> i128, the total length of the set, the sum of hi.value() - lo.value() over the canonical intervals (single points add 0, and it must not overflow for any i64 endpoints); and complement(&self, lo: Bound, hi: Bound) -> Vec<(Bound, Bound)>, the part of the window interval from lo to hi that is not in the set, in the same canonical form, so endpoint kinds flip where the window meets the set (the complement of {[2,4), (6,8]} within [0,10] is [0,2), [4,6], (8,10]); it is empty when the window is empty or fully covered. Also implement std::fmt::Display for IntervalSet: the canonical intervals joined by ", " inside braces, each written as '[' or '(' then lo value, ',', hi value, then ']' or ')' with no spaces inside, for example "{[1,3), (4,5], [7,7]}" or "{(-3,0]}", and "{}" for the empty set. Every operation must work for any i64 endpoints including i64::MIN and i64::MAX without overflowing. The set must also scale: insert, remove and contains must each run in O(log n) amortized time, where n is the number of stored intervals (rescanning, rebuilding or shifting the elements of a Vec of all intervals on every call is too slow; ranges, measure, complement and Display may take time proportional to the set size). Concretely, a workload of 300000 inserts and removes of short intervals (length 0 to 1000) whose positions sweep downward from 1e9 towards 0 with random jitter, so that most new intervals land in front of those already stored, each followed by one contains call at a random point in [0, 1e9], must finish in under 3 seconds in a debug build (cargo test's default profile).

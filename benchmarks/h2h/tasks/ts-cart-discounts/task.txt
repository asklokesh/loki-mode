Add discount codes to the cart. cartTotal in src/cart.ts should take an optional second argument, the code the customer typed, and checkoutSummary in src/checkout.ts should accept and pass one through too. Put the code definitions in a new src/discounts.ts. Codes are case-insensitive and surrounding spaces are ignored. SAVE10 takes 10% off the subtotal (rounded to the nearest cent), FLAT5 takes 500 cents off the subtotal but never below zero, and FREESHIP waives shipping. Free shipping eligibility keeps using the subtotal before any discount. An unknown code should throw an InvalidDiscountError, exported from src/cart.ts. No code (undefined or an empty string) behaves exactly like today.

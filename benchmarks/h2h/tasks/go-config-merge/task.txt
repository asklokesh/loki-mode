The server is starting with the wrong settings. server.Load(fileText, env) builds server.Settings from the config file text and an environment map, and three things go wrong. First, timeout = 1m30s in the file gives the default 30s timeout instead of 90 seconds. Second, running with APP_PORT set to the empty string makes the server ignore port = 9000 from the file and fall back to the default 8080. Third, a value that contains '=' gets cut off, so dsn = user=app password=s3cret ends up as just "user". The server code itself looks right to me, so the problems are probably in the config package. The rules I expect: in the file, only the first '=' on a line separates the key from the value, and everything after it (trimmed) is the value, so config.ParseFile("a = b=c") gives {"a": "b=c"}; the other ParseFile rules stay as they are. config.FromEnv must ignore environment variables whose value is the empty string, exactly as if they were not set, so they never override the file or the defaults (config.FromEnv(map[string]string{"APP_PORT": "", "APP_LOG_LEVEL": "debug"}) returns {"log_level": "debug"}). Config.Duration must accept a plain integer as a number of seconds (as today) and otherwise any string that time.ParseDuration accepts ("1m30s", "250ms", "1.5s", "2h"); anything else falls back to the default. Precedence stays defaults < file < environment for every setting.

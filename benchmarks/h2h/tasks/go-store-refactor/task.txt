Refactor the notes package so it no longer keeps notes in package-level globals. In notes/store.go replace the global map, the nextID counter and the functions Add, Get, List, Delete and Reset with an interface type Store { Add(title, body string) (Note, error); Get(id int) (Note, error); List() []Note; Delete(id int) error } and an in-memory implementation type MemStore created by func NewMemStore() *MemStore (*MemStore must implement Store). Every MemStore is independent: its own notes and its own id counter starting at 1. In notes/handlers.go replace the package-level HandleCreate, HandleShow, HandleList and HandleDelete with a type Handlers built by func NewHandlers(store Store) *Handlers, with methods Create(title, body string) string, Show(id int) string, List() string and Delete(id int) string that do exactly what the old functions did but only through the Store they were given (so they also work with any other Store implementation, and an error from the store is reported as "error: " followed by that error's message). Behaviour must not change at all: titles are trimmed with NormalizeTitle and a blank title fails with ErrTitleRequired without storing anything or using up an id; the body is stored as given; ids are never reused after a delete; List returns notes sorted by id ascending and an empty non-nil slice when there are none; Get and Delete of a missing id return an error wrapping ErrNotFound whose message is "note 7: note not found" (for id 7); the handlers return "created <id>", the FormatNote text, the FormatSummary lines joined with newlines (or "no notes" when empty), "deleted <id>", or "error: <message>". Keep Note, ErrNotFound, ErrTitleRequired, NormalizeTitle, FormatSummary and FormatNote in notes/format.go exactly as they are.

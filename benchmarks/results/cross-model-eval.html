Cross-model harness equivalence

Identical spec, same machine, same harness version. Generated 2026-07-30T04:12:15Z.

What this shows

Both models converged in one iteration, exited 0, and met the acceptance check. The harness ran the same gates and applied the same completion standard regardless of which model was behind it.

What this does not show

This is two models on one small spec. It is evidence that the harness is model-invariant, not evidence that every model produces equal quality. We do not claim identical output across models, because that is not deliverable and asserting it would be the kind of unfalsifiable marketing this project exists to argue against.

Why publish this at all

Nobody in this category publishes a same-harness cross-model evaluation. The market is moving the other way: Bolt collapsed model choice into Standard/Max, Lovable curates a fixed menu, and OpenHands' own docs advise using "the strongest model you can afford". Broad provider support is table stakes. Demonstrating that outcomes hold across models is unclaimed.

The honest claim

The harness is model-invariant: the same gates actually run, the receipt tells the same truth, and when a model is too weak you are told rather than silently given less. That is narrower than "same results on any model" and it is the version we can defend with measurement.

Raw data: benchmarks/results/cross-model-eval.json. Source runs: speed-agnostic-haiku and speed-agnostic-sonnet, both engine-completed with build_exit_code: 0. Extending this to open models via the opencode provider is the next step, and until it is run those results are not asserted here.
